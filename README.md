# Texas Hold'em — 多人联网德州扑克

一个纯前端、基于 WebRTC (PeerJS) 的多人德州扑克网页应用，支持最多 **8 名真人玩家**同台竞技。可直接通过 GitHub Pages 托管访问，无需后端服务器。

## 快速开始

1. **创建房间**：打开页面 → 输入名字 → 点击「创建房间并开始」
2. **分享链接**：复制房间链接/房间号给朋友们
3. **加入游戏**：其他人打开链接或输入房间号 → 输入名字 → 加入
4. **开始游戏**：房主点击「开始游戏」，至少需要 2 名玩家

## 功能

- **房间系统**：创建/加入房间，通过 URL 链接邀请
- **经典德州扑克规则**：翻牌前 → 翻牌 → 转牌 → 河牌 → 摊牌
- **完整 Betting 动作**：弃牌、过牌、跟注、加注（滑块选择金额）、All-in
- **BB 选项**：翻牌前大盲注位置获得过牌/加注选择权
- **自动下一局**：摊牌/提前结算后自动准备新一局（房主可点击「下一局」跳过等待）
- **超时弃牌**：玩家 60 秒未操作自动弃牌，避免卡局
- **牌型智能判断**：自动计算最佳牌型并分配底池
- **房主权威**：房主控制游戏流程，处理发牌/结算
- **断线处理**：断线玩家自动弃牌，不影响其他玩家
- **8 座位布局**：椭圆形牌桌，玩家始终位于底部中央
- **连接状态指示器**：实时显示与房主的连接状态
- **沉浸式界面**：绿色牌桌、扑克牌动画、筹码显示、状态徽章

## 技术架构

| 组件 | 方案 |
|------|------|
| 实时通信 | WebRTC via PeerJS (公共 signaling 服务器) |
| 房间协调 | 星形拓扑：房主为 Hub，同步游戏状态 |
| 游戏引擎 | 房主浏览器端权威执行 |
| 托管方式 | 纯静态，GitHub Pages 友好 |
| 外部依赖 | PeerJS 前端库随站点静态托管 |

### 消息流程

- 房主创建 PeerJS 连接，分配 6 位房间号
- 加入者通过房间号连接房主
- 房主执行发牌、回合管理、摊牌结算
- 私有手牌通过点对点通道单独发送
- 状态变更广播给所有玩家

## 限制

- **WebRTC 在部分网络环境可能受限**（严格 NAT、企业防火墙）。若无法连接，请尝试切换网络。
- **房主断线则游戏结束**。这是纯前端无服务器的固有限制。未来可引入 Relay 或 TURN 服务器改善。
- **不支持底池分割（side pot）**。All-in 多人场景只使用单一主池。
- **Bootstrap 轮空位**：座位按加入顺序分配，无法选座。

## 本地开发

本项目为纯静态文件，无需构建步骤：

```bash
# 使用任意静态服务器启动
npx serve .
# 或
python -m http.server 8080
```

然后在浏览器打开 `http://localhost:8080`。

也可直接双击 `index.html` 打开（但 PeerJS 在某些浏览器需要 http(s) 环境）。
